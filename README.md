# projeto_ciberseguranca_alura
Tratamento de dados utilizando Python. Case: Uma empresa de médio porte enfrenta um volume crescente de chamados relacionados à segurança da informação, como tentativas de invasão, phishing, acessos não autorizados, incidentes de malware e vunerabilidades detectadas.
Muitos chamados são repetidos para o mesmo incidente ou o mesmo usuário, dificultando a priorização e a resposta.
A equipe de cybersegurança precisa analisar os dados dos chamados e logs. Para isso, será preciso:
- Identificar os motivos mais frequentes e críticos dos incidentes.
- Detectar motivos que geram chamados repetidos ou suspeitos.
- Mapear padões de comportamento que indiquem possíveis fraudes ou ataques.
- Priorizar os incidentes para resposta eficiente.
- Criar dashboards e relatórios para monitoramento em tempo real.
Objetivo é analisar as fontes de dados e propor  uma inteligência analítica em 
contribuição na conformidade com as normas e políticas de seguranças internas.
Metas:
- Eficiência operacional
- Tomada de decisão baseada em Dados
- Contribuição com conformidade e relatórios que comprovem o monitoramento de acessos e proteção de dados de forma contínua.
